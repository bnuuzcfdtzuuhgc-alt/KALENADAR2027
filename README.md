# Настенный календарь 2027 — сайт + админка + Supabase

## Файлы
- `index.html` — календарь с анимацией перелистывания (обложка + 12 месяцев).
- `admin.html` — админка: вход по email и паролю, загрузка, замена и удаление картинок.
- `config.js` — ключи Supabase и год. **Заполнить перед запуском.**
- `supabase.sql` — создаёт хранилище, таблицы и права доступа.
- `vercel.json` — настройки для Vercel (адрес `/admin` без `.html`).

Пока картинок в Supabase нет, календарь показывает пробные картинки, нарисованные кодом.

## Настройка за 5 шагов

1. **Supabase → New project.**
2. **SQL Editor → New query.** Вставь `supabase.sql`, в последней строке замени `admin@example.com` на свой email, нажми **Run**.
3. **Authentication → Users → Add user → Create new user.** Укажи тот же email и пароль, поставь галочку **Auto Confirm User**.
   Для безопасности: **Authentication → Sign In / Providers → Email** выключи **Allow new users to sign up**, чтобы никто чужой не зарегистрировался.
4. **Project Settings → API:** скопируй **Project URL** и **Publishable key** (sb_publishable_…) в `config.js`.
   Ключ `sb_secret_…` / `service_role` никуда не вставляй.
5. **Залей папку на Vercel** (через GitHub или перетаскиванием) — сборка не нужна, это статический сайт.

Готово:
- календарь — `https://твой-сайт.vercel.app/`
- админка — `https://твой-сайт.vercel.app/admin`

## Как грузить картинки
- Перетащи файл на нужный лист или нажми «Загрузить» / «Заменить».
- «Загрузить пачкой»: 13 файлов — обложка + 12 месяцев; 12 и меньше — заполняются с января. Порядок по имени файла, называй `01.jpg … 12.jpg` (обложку — `00.jpg`).
- Картинки сами ужимаются до 2400 px (JPEG), старый файл при замене удаляется.
- Размеры: месяцы ≈ 1.13 : 1 (2400×2120), обложка ≈ 2 : 2.9 (2000×2900). Другие пропорции тоже подойдут — картинка обрежется по краям.

## Ещё
- Добавить второго админа: в SQL Editor выполни
  `insert into public.admins (email) values ('второй@почта.ru');` и создай этому email пользователя (шаг 3).
- Новый год: поменяй `YEAR` в `config.js` — у каждого года свои листы, старые картинки сохраняются.
- Забыл пароль: Authentication → Users → у пользователя «Send password recovery» или задай новый пароль там же.
- Проверить локально: открой папку через любой локальный сервер (например `npx serve`), просто двойной клик по файлу может не сработать.
